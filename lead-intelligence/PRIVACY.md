# Privacy and Data Boundary

This repository is currently **public**.

Therefore the repository may contain:

- scoring methodology;
- schemas;
- source-class definitions;
- sanitised examples;
- aggregated metrics;
- public research methodology.

It must **not** contain a working CRM/lead dataset with personal contact details, private correspondence, inferred personal attributes or other data that does not need to be public.

## Canonical split

- GitHub = canonical rules, schemas, methods and public-safe research artifacts.
- CRM/private datastore = canonical operational account/contact records.
- Exports into this public repo must be sanitised.

If a future decision makes the repository private and access-controlled, this boundary can be reconsidered explicitly. Do not silently migrate personal lead data merely because it exists in an Excel workbook.
