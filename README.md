# ZorgTechAdvies

Canonical source of truth for strategy, doctrine, commercial intelligence, content, website and operating roadmap of ZorgTechAdvies.

## Operating principle

**GitHub is source of truth.** Strategy, lead-intelligence rules, content, website source and deployment configuration are versioned here. Cloudflare is a deployment target, not an editing source.

## Core commercial line

ZorgTechAdvies helps care organisations make and execute defensible choices in care technology. The **KetenScan** remains the primary flagship entry point when the real problem and route are not yet sufficiently clear. Where an organisation is already in selection, implementation, reset, Proof of Value or portfolio standardisation, the phase-appropriate proposition may be the direct next step.

## Repository map

- `strategy/` — positioning, commercial model, market definition and decisions
- `doctrine/` — care-critical-chain doctrine, editorial method, voice and quality gates
- `offers/` — productised propositions and routing logic
- `lead-intelligence/` — screening model, source classes, phase model and operational data
- `content/` — editorial framework, content register and publication pipeline
- `research/` — research dossiers and proprietary intelligence
- `website/` — website source, content model, snapshots and deployment architecture
- `automation/` — AI-assisted triage, extraction and repurposing contracts
- `metrics/` — operating scorecard and learning rules
- `roadmap/` — phased implementation roadmap
- `archive/` — reviewed source artifacts and historical material

## Governance

Facts, inferences, hypotheses, verified facts and commercial decisions are distinct states. No desk-research hypothesis becomes an opportunity without verification. No external publication is released without human review.

See `ARCHITECTURE.md` and `roadmap/ROADMAP.md` for the current operating model.
